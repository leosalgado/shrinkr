# shrinkr: A Fast Byte Compression Library For Python

[![PyPI - Version](https://img.shields.io/pypi/v/shrinkr?color=blue)](https://pypi.org/project/shrinkr/) [![Tests](https://github.com/leosalgado/shrinkr/actions/workflows/tests.yaml/badge.svg)](https://github.com/leosalgado/shrinkr/actions/workflows/tests.yaml)

## Instal with pip

```bash
pip install shrinkr
```

## CLI Usage:

### Compressing:

```bash
shrinkr compress "filename"
```

### Decompressing:

```bash
shrinkr decompress "filename.leo"
```
